# devbox (edge and media node)

Headless Ubuntu box (2 cores / 4 threads, 8 GB, 1 TB HDD) on Wi-Fi (`wlp3s0`) at `192.168.0.172` (DHCP reservation) and `100.109.219.37` on the tailnet (`devbox`). User `aravind` has passwordless sudo.

## What starts after a reboot

| Area | Units |
|---|---|
| Fleet edge | `caddy` (proxy and portal at `/srv/fleet-portal`), `fleet-dns` (dnsmasq for `*.home.arpa` on the tailnet IP), `fleet-mdns` (`*.local` via Avahi), `fleet-agent` |
| Media | `stack@media-server` (Jellyfin, qBittorrent; containers `unless-stopped`) |
| Network and security | `tailscaled`, `ssh` (key-only), `media-lan-filter` (iptables `MEDIA-LAN` in `DOCKER-USER`; `netfilter-persistent` is disabled so no stale snapshot is restored), `avahi-daemon`, `wifi-powersave-off` |
| System | `docker`, `zswap-enable`, `unattended-upgrades`, plus Ubuntu defaults |
| Rex | Personal server for `aravind`: `systemctl --user` `rex.socket` (socket-activated, lingering on), enabled at boot (`systemctl --user enable rex.service`) and started with `--tailscale` via the drop-in `rex/tailscale.conf`, so it is on the tailnet as `rex.tail6f092f.ts.net` (owner-only access). The packaged system `rex.service` and `rex-login-server.service` (account `rex`) are disabled; nothing used them. |

## Layout on the host

- `~/dev/fleet`: runtime copy of this repo (rsync from the workstation, only devbox's stacks). Holds `stacks/media-server/.env`. `.deployed-revision` records the synced commit.
- `~/dev/dotfiles`: runtime copy of the dotfiles repo.
- `~/data/media`: media library and Jellyfin/qBittorrent config (`~/entertainment` is a compatibility symlink). `~/data/9router` holds data from the retired devbox 9router.
- `~/infra/Makefile`: wrapper for `stacks/stacks.sh` (`make -C ~/infra status|health`).
- Generated by `edge/setup-edge.sh`: `/etc/caddy/Caddyfile`, `/etc/fleet/{dnsmasq.conf,mdns-hosts}`, the `# BEGIN FLEET HOSTS` block in `/etc/hosts`.

## Setup from scratch

`hosts/devbox/system/setup-system.sh`, install Docker, Caddy, Avahi, dnsmasq (`dnsmasq-base` is enough) and Tailscale (disable key expiry), run `stacks/setup-stacks.sh`, then `bin/fleet apply devbox` from the workstation and add the Tailscale split-DNS nameserver (see the main README).

## Notes

- `tailscale serve` changes need `sudo` here (no operator is set). The serve config forwards HTTPS 443 to Caddy and 8096/8081 to the media apps.
- Jellyfin transcoding is heavy for 2 cores; clients should direct-play where possible.
